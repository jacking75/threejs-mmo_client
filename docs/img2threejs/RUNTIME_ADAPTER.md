# 아바타·장비 런타임 계약

## 아바타

- `createRuntimeAvatar`는 절차형 `AvatarGroup`을 안전한 fallback으로 보존한다. 여성형 전사는 GLB 로딩과 리그 검증이 끝나면 GLB를 표시하고 실패하면 절차형 외형을 표시한다.
- 절차형/GLB 경로 모두 `root`, `head`, `hand.R`, `hand.L`, `back`과 이름 있는 사지 피벗을 `avatar.userData.sculptRuntime`으로 노출한다.
- `AvatarAdapter`는 외부 DCC 본 이름 별칭을 canonical 노드에 매핑하고 선택적 GLTF 애니메이션 클립을 `AnimationMixer`에 연결한다. 현재 여성 전사 GLB는 클립이 없어 절차 애니메이션을 사용한다.
- `AvatarRenderer`는 상태에 따라 피벗을 애니메이션하고 `EquipmentRenderer`는 직렬화된 장비 ID를 시각 팩토리와 연결한다. GLB와 팩토리는 게임 상태·카메라·게임 루프를 소유하지 않는다.
- GLB가 준비되면 소켓 부착물을 새 리그 소켓으로 옮긴다. 장비가 로딩 전후에 같은 소켓 계약을 유지하는지 확인한다.

## 강체 장비

- 무기 팩토리의 그립 원점은 `(0, 0, 0)`이다. 검의 칼끝과 지팡이 상단은 로컬 `+Y`를 향한다. 각 팩토리가 축·그립·이름 있는 애니메이션 노드를 문서화한다.
- 검과 지팡이는 `hand.R`, 활은 `hand.L` 소켓에 부착한다. 절차형 손과 GLB 손의 휴지 회전 차이는 장비 어댑터에서 보정한다.
- 생성된 그룹은 전역 씬을 참조하지 않는다. 교체·종료 시 하위 geometry와 material을 중복 없이 해제한다.
- 게임 도메인 카탈로그의 ID·무기 종류와 시각 팩토리 등록을 함께 연결해야 플레이어가 장착할 수 있다. 갤러리 등록만으로 게임 아이템이 되지는 않는다.

## 애니메이션

장착한 무기에 따라 검 베기, 지팡이 마법 시전, 활 당기기와 발사 동작을 선택한다.
공격 구간이 끝나기 전에는 이동 애니메이션으로 덮어쓰지 않으며 종료 후 현재 입력에 맞는 상태로 복귀한다.
무기 교체와 공격 반복, 절차형/GLB 아바타, 새로고침 복원을 브라우저에서 확인한다.
